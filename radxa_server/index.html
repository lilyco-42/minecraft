常用命令 (点击发送)

kill @e[type=item]清理掉落物
tps查看性能 (Paper)
📖 手册: 命令怎么用

玩家管理
· op 玩家名 — 给管理员, 之后玩家在游戏里可用全部命令
· whitelist add 玩家名 — 白名单是正经玩家名字(大小写敏感), 开启后只有名单内的人能进
· ban 玩家名 封禁, ban-ip IP 封 IP, pardon 解封
· kick 玩家名 踢出(不封禁)

世界与时间
· time set day|noon|night|midnight 或 time set 0-24000
· difficulty peaceful 和平(无怪), easy 轻松(当前), normal 普通, hard 困难
· gamemode survival|creative|adventure|spectator 玩家名
· give 玩家名 物品 数量 — 如 give Steve diamond 64
· tp 玩家A 玩家B 传送, tp 玩家 x y z 坐标传送

服务器维护
· save-all 保存, 备份 world 文件夹前先 save-off → 拷贝 → save-on
· stop 安全关服 (面板停止按钮同款)
· tps / spark profiler — Paper 性能诊断

提示: 命令不带开头的斜杠; 中文玩家名可直接输入

🔧 远程 radxa 上的东西在哪

· 服务端目录: ~/mc/server/minecraft (Paper jar / world / plugins)
· 启动脚本: ~/mc/server/setup.sh (幂等, 已在运行则跳过)
· 会话: screen -r mc (SSH 里手动查看), 面板相当于自动帮你 stuff 命令
· 端口: 25565 (Minecraft), radxa IP 由 mDNS radxa-cubie-a7a.local 自动发现
· 日志: ~/mc/server/minecraft/logs/latest.log (面板增量实时读取)
